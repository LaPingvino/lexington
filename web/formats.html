Formats

Lexington is Pandoc for screenplays. It converts any format it reads into any it writes: Fountain, Final Draft, Fade In, Trelby, KIT Scenarist, Celtx and PDF, to those and to Word, OpenDocument, HTML, LaTeX, EPUB and more. It reads screenplay PDFs, scanned ones too (with OCR, in the lexington command). It is free software (MIT), a command line tool and a Go library, and this page's converter runs it in your browser.
